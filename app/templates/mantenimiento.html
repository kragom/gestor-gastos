¿Qué es esto?

El servidor gratuito (Render) duerme la app tras un rato sin uso. Una tarea en GitHub la mantiene despierta, pero usa un token que caduca. Cuando caduque (o si lo regeneras por seguridad), pégalo aquí y la app lo actualizará automáticamente. El token no se guarda en la aplicación: solo se usa para guardarlo cifrado en GitHub.

Cómo generar el token en GitHub

Generar token en GitHub →

Este enlace abre GitHub con los permisos repo y workflow ya marcados. Solo tienes que elegir la caducidad, pulsar Generate token y copiar el valor (empieza por ghp_).

  1. Abre el enlace de arriba (o entra en github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)).
  2. Comprueba que están marcados repo y workflow.
  3. En caducidad elige lo que prefieras (a más tiempo, menos mantenimiento).
  4. Pulsa Generate token (classic) y copia el token.
  5. Pégalo abajo y pulsa Actualizar.

Si prefieres hacerlo a mano

También puedes actualizar el secret directamente en GitHub y luego relanzar el workflow:
